# Composición de módulos

## Objetivo
Componer módulos pequeños en una solución mayor.

## Práctica
Diseña una solución que use módulos de almacenamiento y observabilidad, pasando outputs entre módulos cuando exista una dependencia real.

## Preguntas
- ¿Qué hace que un módulo sea demasiado grande?
- ¿Cómo se comunican los módulos?
