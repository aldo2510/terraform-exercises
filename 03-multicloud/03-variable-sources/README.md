# Fuentes de variables

## Objetivo
Practicar las formas de proporcionar valores a variables Terraform.

## Fuentes
- terraform.tfvars
- archivos *.auto.tfvars
- -var
- -var-file
- TF_VAR_*

## Preguntas
- ¿Cuál usarías en desarrollo local?
- ¿Cuál evitarías para secretos?
- ¿Qué valores deberían gestionarse mediante el mecanismo de secretos del CI/CD?

No commits credenciales ni secretos en archivos de variables.
