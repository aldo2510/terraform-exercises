# Azure Lab 03 — Azure Key Vault

## Objetivo
Practicar un servicio administrado y entender la diferencia entre configuración y secretos.

## Pasos
1. Crear Resource Group.
2. Crear Key Vault con configuración segura y mínima.
3. Parametrizar tenant y nombre.
4. Aplicar tags.
5. Exponer únicamente metadata no sensible.
6. Revisar el state y discutir por qué los secretos requieren cuidado especial.
7. Destruir.

## Nota
No subir secretos reales al repositorio.
