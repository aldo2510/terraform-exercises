# Lab Azure 04 — Log Analytics

## 🎯 Objetivo
Parametrizar un Workspace de observabilidad y validar inputs.

## 📝 Actividad
1. Definir location.
2. Definir SKU.
3. Definir retención.
4. Agregar validation.
5. Crear Resource Group y Workspace.
6. Ejecutar `plan`.
7. Aplicar.
8. Cambiar retención y analizar el plan.
9. Destruir.
