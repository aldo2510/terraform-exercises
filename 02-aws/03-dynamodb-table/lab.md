# AWS Lab 03 — DynamoDB

## Objetivo
Practicar resources con atributos y estructuras específicas de AWS.

## Pasos
1. Crear una tabla DynamoDB.
2. Parametrizar nombre, hash key y capacidad/configuración adecuada al modo seleccionado.
3. Aplicar tags.
4. Crear outputs con nombre y ARN.
5. Cambiar una variable y observar el plan.
6. Destruir.
