# AWS Lab 04 — CloudWatch Log Group

## Objetivo
Crear un recurso de observabilidad y practicar lifecycle.

## Pasos
1. Crear un Log Group.
2. Parametrizar retention.
3. Validar que retention sea un valor permitido.
4. Aplicar.
5. Cambiar retention y observar el plan.
6. Agregar `lifecycle` con una regla apropiada para el laboratorio.
7. Destruir.
