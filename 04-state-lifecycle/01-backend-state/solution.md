# Solución — Backend y State

La solución muestra la transición desde State local hacia un backend remoto apropiado para el cloud utilizado.

## Conceptos para explicar

- State
- backend
- locking
- colaboración
- seguridad
- migración de State

El backend concreto debe configurarse según el cloud y las capacidades disponibles para el laboratorio. No se incluyen credenciales en el repositorio.
