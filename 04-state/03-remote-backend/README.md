# Backend remoto

## Objetivo
Entender por qué los equipos utilizan un backend remoto para compartir el state.

## AWS
S3 es una opción habitual. El bucket debe existir antes de inicializar el backend.

## Azure
Azure Storage puede utilizarse para almacenar el state.

## Práctica
Configura un backend remoto en un entorno de laboratorio y ejecuta terraform init.

## Preguntas
- ¿Por qué el backend se inicializa antes de crear recursos?
- ¿Qué problema resuelve el state remoto en un equipo?
