# Lab Expressions 02 — Dynamic blocks

## 🎯 Objetivo
Generar bloques anidados dinámicamente.

## 👨‍🏫 Guion del instructor
Aclarar que `dynamic` genera bloques dentro de un resource; no crea resources independientes.

## 📝 Actividad
1. Identificar un bloque repetible.
2. Definir una colección.
3. Crear primero el bloque estático.
4. Convertirlo a `dynamic`.
5. Ejecutar `plan`.
6. Agregar un elemento.
7. Comparar el plan.

## 💬 Preguntas
- ¿Cuándo usar dynamic?
- ¿Cuándo es mejor mantener bloques explícitos?
- ¿Qué diferencia existe entre dynamic y for_each?

## 💡 Reto
Agregar validaciones al objeto usado por el dynamic block.
