# Lab 02 — Dynamic blocks

## Objetivo
Generar bloques anidados de forma declarativa.

## Pasos
1. Seleccionar un recurso AWS o Azure que tenga un bloque anidado repetible.
2. Modelar la configuración como una lista/mapa de objetos.
3. Crear un `dynamic` block.
4. Agregar y eliminar elementos de la colección.
5. Revisar el diff generado por Terraform.

## Reto
Evitar duplicar bloques de configuración.
