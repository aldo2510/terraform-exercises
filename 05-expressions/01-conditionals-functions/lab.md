# Lab Expressions 01 — Condicionales y funciones

## 🎯 Objetivo
Usar expresiones HCL para construir configuraciones reutilizables.

## 👨‍🏫 Guion del instructor
Explicar primero la expresión y después mover la lógica repetida a locals.

## 📝 Actividad
1. Normalizar strings.
2. Combinar mapas con `merge`.
3. Usar `lookup`.
4. Usar operador condicional.
5. Crear valores derivados con locals.
6. Ejecutar `terraform console`.
7. Integrar las expresiones en un resource.
8. Ejecutar `plan`.

## 💬 Preguntas
- ¿Cuándo una expresión es demasiado compleja?
- ¿Por qué mover lógica a locals?
- ¿Qué funciones trabajan con colecciones?

## 💡 Reto
Construir nombres diferentes para dev, qa y prod.
