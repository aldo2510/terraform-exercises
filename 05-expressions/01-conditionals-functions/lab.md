# Lab 01 — Expresiones, funciones y condicionales

## Objetivo
Usar expresiones Terraform para construir configuraciones dinámicas.

## Pasos
1. Crear variables para ambiente y región.
2. Usar operadores condicionales.
3. Usar funciones como `lower`, `upper`, `join`, `concat`, `merge` y `lookup`.
4. Generar nombres de recursos dinámicamente.
5. Generar tags a partir de mapas.
6. Validar el resultado mediante outputs.
