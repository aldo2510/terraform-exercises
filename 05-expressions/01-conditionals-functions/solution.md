# Solución — Condicionales y funciones

La solución debe separar valores de entrada de valores derivados.

Ejemplos:

- `lower()` para normalizar nombres.
- `join()` para construir identificadores.
- `merge()` para combinar tags.
- `lookup()` para obtener valores de mapas.
- Operador ternario para seleccionar configuración por ambiente.

La recomendación es mantener expresiones complejas en `locals.tf` en lugar de repetirlas dentro de resources.
