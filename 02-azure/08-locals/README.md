# Locals — Azure

## Objetivo
Aprender a centralizar valores derivados con locals.

## Práctica
Define project y environment, crea un local name_prefix y úsalo para nombrar un Resource Group y Storage Account.

## Preguntas para el alumno
- ¿Qué diferencia hay entre una variable y un local?
- ¿Qué valores conviene derivar con locals?

## Error intencional
Duplica manualmente el prefijo y luego reemplázalo por el local.

## Solución
La configuración Terraform de este directorio representa la solución.

## Limpieza
Ejecuta terraform destroy al finalizar.
