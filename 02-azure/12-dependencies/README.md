# Dependencias — Azure

## Objetivo
Distinguir dependencias implícitas y explícitas en Azure.

## Práctica
Crea recursos relacionados mediante referencias directas y usa depends_on únicamente cuando sea necesario.

## Preguntas
- ¿Por qué una referencia de atributo suele ser preferible?
- ¿Qué aporta una dependencia explícita?

## Error intencional
Agrega dependencias redundantes y analiza la configuración.

## Solución
La configuración Terraform de este directorio representa la solución.
